# Semana 02

Se creó un entorno virtual llamado `venv` en la raíz del repositorio.

Para crearlo se utilizó `python -m venv venv`.

El entorno se activó con `venv\Scripts\activate`.

Se verificó la activación comprobando que apareciera `(venv)` en la terminal.

Se instaló `matplotlib` utilizando `pip install matplotlib`.

Las dependencias se registraron con `pip freeze > requirements.txt`.

Para reproducir el entorno se debe crear y activar nuevamente el `venv`.

Finalmente, se deben instalar las dependencias con `pip install -r requirements.txt`.
